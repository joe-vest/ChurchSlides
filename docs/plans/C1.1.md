# C1.1: Domain model and serialization

Size M. Project: `ChurchSlides.Domain` (no dependencies) plus `ChurchSlides.Domain.Tests`.
FRD: section 3, section 4, SLD-001, SLD-005, SLD-009, LIB-003, LIB-004, FUT-001.
ARCH: section 5 (domain model), section 8.3 (schema), D-3, D-8.

## Goal

Every persisted entity exists as an immutable C# type that serializes to and from stable, human-readable JSON, with a versioned file envelope. No behavior beyond trivial helpers. Resolution logic is C1.2, file I/O is C1.3.

## Decisions made for this chunk

| # | Decision | Reason |
|---|---|---|
| 1 | **Code names differ from glossary for four colliding terms:** `Action` → `TriggeredAction`, `Timer` → `CountdownTimer`, `Trigger` → `ActionTrigger`, `TextBox` → `SlideTextBox`. UI labels and FRD wording stay "Action", "Timer", "Trigger", "Text Box". Owner approved. | They collide with `System.Action`, `System.Threading.Timer`, `System.Windows.Trigger`, `System.Windows.Controls.TextBox`. |
| 2 | **Schema policy:** any change to a saved file's shape bumps its schema version. A file newer than the app opens read-only with a warning. No extension-data round tripping. Owner approved. | The app can never silently drop fields written by a newer version on the other machine. |
| 3 | **Immutable records with `ImmutableArray<T>`**, init-only properties with `= []` defaults (not positional), `required` on identity fields. | Editing is `with`; undo snapshots (SAFE-003) are just retained references. Defaults avoid the uninitialized `default(ImmutableArray)` trap when a JSON field is missing. |
| 4 | **Typed IDs:** `Id<T>` readonly struct wrapping a `Guid`, serialized as a plain GUID string. Example: `Id<Show>`, `Id<Slide>`, `Id<ServiceItem>`. | Stops swapped-argument bugs such as `GoToSlide(item, slide)`. If a generic converter doesn't work with source generation, fall back to hand-written per-entity ID structs. |
| 5 | **`LibraryRelativePath`** value type for media references. Rejects rooted paths, drive letters, UNC, and `..`. Normalizes to forward slashes. | LIB-003: absolute paths must never be stored. Enforced by the type. |
| 6 | **JSON conventions:** `System.Text.Json` source generation only (reflection disabled in tests), camelCase, enums as camelCase strings, nulls omitted, indented output, `$type` discriminator for polymorphic types with out-of-order metadata allowed. | Fast, trimmer-friendly, diff-friendly in Drive. |
| 7 | **Envelope:** `{ "schemaVersion": 1, "data": { ... } }` per file. One current version constant per file kind. | LIB-004. |

## Deviations found during execution

These replace the matching rows above. Recorded 2026-11-23.

| Plan said | What was built | Why |
|---|---|---|
| Decision 3: `required` on identity fields, `= []` defaults cover missing JSON fields | **No `required` keyword.** Every non-optional property carries `[JsonRequired]`; `RespectNullableAnnotations` and `RespectRequiredConstructorParameters` are on. A file missing a non-optional field, or holding null in one, is `Unreadable` and the error names the field. | Source-generated deserialization sets *every* init-only property, so a missing field became `default(ImmutableArray)` or null instead of its initializer (the test for this caught it). Strict presence is simpler than patching defaults. The app always writes complete files, and migrations (C1.3) will upgrade old ones. Compile-time "forgot the Id" safety is traded away: C1.3 must reject empty IDs on save. |
| Decision 6: enums as camelCase strings | Enums are **PascalCase strings** (`"Song"`, `"FirstSlide"`). | The source generator rejects a custom camelCase enum converter (SYSLIB1034). Property names and `$type` values are camelCase. |
| Decision 6: indented output | Output is written through `Utf8JsonWriter` with `\n` newlines and relaxed escaping. | Same bytes on every machine, and accents in lyrics stay readable instead of `ñ`. |
| `Inline.Format` implied non-null | `Inline.Format` is **nullable**; null means no explicit formatting. `RunFormat.None` is provided. | Avoids `"format": {}` on every run in every lyric file. |
| (not planned) | `ServiceItem.Id` is pinned to the top of each item (`JsonPropertyOrder(-1)`). | Keeps `$type` and `id` together in long items. |
| Test group 4 "missing collections load empty" | Replaced by "missing non-optional field is unreadable and named", "optional fields may be absent", "null in a non-nullable field is unreadable". | Follows from the strict policy above. |
| (not planned) | `.gitattributes` forcing LF for `*.json`; `InternalsVisibleTo` for the test project (to simulate older/newer file versions before a second version exists). | Golden files must match byte for byte on Windows checkouts. |

## Types to create (`src/ChurchSlides.Domain`)

Folders `Model/`, `RichText/`, `Serialization/`.

- **Ids:** `Id<T>`, `LibraryRelativePath`.
- **Rich text** (D-3): `RichText` (paragraphs), `Paragraph`, `Inline` (sealed hierarchy: `TextRun`, `TokenRun`), `RunFormat` (all nullable: font family, size as fraction of canvas height, color hex, bold, italic), `Token` hierarchy (`VariableToken`, `TimerToken`, `ShowMetadataToken` with a field enum, `ChurchLicenseToken`). Helpers: `RichText.ToPlainText()` (tokens as `{{...}}` markup, used later by search and the remote) and `Token.ToMarkup()`. Token parsing is C1.2.
- **Layout:** `RectRelative`, `Background` (`MediaKind` Image or SolidColor, `LibraryRelativePath?`, color, `BackgroundFit`), `TextDefaults`, `Outline`, `Shadow`, alignment enums.
- **Templates:** `Template`, `TemplateBox` (`IsCopyrightBox`).
- **Shows:** `Show` (Kind, CategoryId, Tags, `SongMetadata?`, DefaultTemplateId, Slides, `AudioTrack?`, Actions, CopyrightPlacement), `Slide` (label, template override, background override, text boxes, Actions), `SlideTextBox` (bound template box name or detached with geometry; optional horizontal/vertical alignment and line-spacing overrides for SLD-023), `AudioTrack`, `Cue` (absolute file time).
- **Actions:** `TriggeredAction` (trigger, delay, commands). `ActionTrigger` hierarchy: `ServiceStarted`, `ShowStarted`, `ShowEnded`, `SlideDisplayed`, `SlideEnded`, `TimerExpired(name)`, `AudioEnded`. `Command` hierarchy: `NextSlide`, `PreviousSlide`, `NextItem`, `PreviousItem`, `GoToSlide(SlideTarget)`, `GoToItem(item)`, `StartAudio`, `StopAudio`, `Clear`, `Black`, `Logo`, `StartTimer(name)`, `StopTimer(name)`. `SlideTarget`: slide ID plus optional item ID (null means "within the current Show", FRD v0.2 ACT-022).
- **Services:** `Service` (name, date, mode, items, variables, timers, Actions, source Service Template ID). `ServiceItem` sealed hierarchy with discriminator: `ShowReferenceItem` (show ID, skipped slide IDs, optional remembered `PlaceholderSpec` for SVC-033), `ShowCopyItem` (local `Show` plus `OriginShowId` so "Revert to catalog version" works, SVC-024), `PlaceholderItem`, `ScriptureItem` (`ScriptureSpec` plus generated local `Show`). Every item has an `Id<ServiceItem>`, an optional template override (COULD, TPL-011), and item-level Actions (ACT-002). `Variable`, `CountdownTimer` (as FRD sketch), `ServiceMode`.
- **Service Templates:** `ServiceTemplate` (items restricted by convention to references, placeholders and scripture stubs, variable definitions with defaults, timers, Actions).
- **Library:** `Category`, `CategoryList`, `LibrarySettings` (canvas aspect, CCLI license number, logo path, transition and duration, copyright format string, default Template ID, default Scripture Template ID, CCLI reporting period).
- **Serialization:** `ChurchSlidesJson` (source-generated context and shared options), `FileKind` and `SchemaVersions` constants, `VersionedFile` (serialize with envelope; deserialize to `LoadResult<T>`), `LoadResult<T>` (value, file version, `IsReadOnly` when the file is newer, `NeedsMigration` when older, or a failure with a message).
- **Trivial helpers only:** `Show.DefaultCopyrightPlacement(ShowKind)` (SHOW-004 assumption: Songs First Slide, Presentations None).

## Not in this chunk

Validation rules (variable names, unique names, category deletion), token parsing, template resolution, `IdRemapper`, migrations and the migrator chain (C1.3), file and folder I/O, hex color parsing, CCLI log and Bible record types (their own chunks), UI of any kind.

## Tests (`ChurchSlides.Domain.Tests`, test-first)

The test project sets `JsonSerializerIsReflectionEnabledByDefault=false`, so any type missing from the source-generated context fails loudly.

1. **Round trip, every entity** (Show, Service, Template, ServiceTemplate, CategoryList, LibrarySettings): build a fully populated sample, serialize, deserialize, re-serialize, and the JSON is identical. Spot-check fields. Covers SLD-001/005/009.
2. **Polymorphism:** each `ServiceItem` kind, `ActionTrigger`, `Command`, `Inline` and `Token` survives with its concrete type. Metadata properties may appear in any order in hand-edited JSON.
3. **Forward compatibility (policy 2):** a file with `schemaVersion` newer than current and extra unknown fields loads with `IsReadOnly = true`. An unknown `$type` yields a failed `LoadResult` with a readable message, never an exception. An older version reports `NeedsMigration`. (LIB-004)
4. **Missing fields:** JSON omitting optional collections yields empty arrays, never `default(ImmutableArray)`.
5. **`LibraryRelativePath`:** accepts `media/images/a.png` and backslash input (normalized). Rejects `C:\x.png`, `\\server\share\x`, `/abs`, `..\x`, empty. JSON round trip. (LIB-003)
6. **`Id<T>`:** serializes as a bare GUID string. `Id<Show>` and `Id<Slide>` are distinct types (compile-time).
7. **Golden files:** hand-reviewed JSON samples in `tests/ChurchSlides.Domain.Tests/Samples/` for a Song with audio and cues, a Service with one of each item kind, a Template. The test loads them and also asserts that serializing the in-memory sample reproduces them byte for byte. Any accidental format change fails here and forces a schema version decision.
8. **Helpers:** `ToPlainText` with tokens and multiple paragraphs, `DefaultCopyrightPlacement`.
