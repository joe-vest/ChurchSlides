# C1.2: Resolution logic (review gate)

Project: `ChurchSlides.Domain` (pure functions, no I/O, no clock) plus `ChurchSlides.Domain.Tests`.
FRD: TPL-001..027, VAR-001..006, CCLI-003..005, SLD-006, SVC-020..025, SVC-035, DEC-005, DEC-006, AS-05, AS-06 (logic part).
ARCH: section 5.1 (resolution pipeline), 5.2 (IDs), D-3, D-8.

## Goal

The rules that decide **what a slide looks like** and **how Shows and Services are copied**, as pure, fully tested functions. Everything the renderer, editor and presenter later rely on is settled here, so those chunks don't also debug semantics.

## Split into two sub-chunks

Together they exceed the sizing rule, so they run as two chunks with a commit between them. Both plans are covered by this review.

| Sub-chunk | Scope |
|---|---|
| **C1.2a: Slide resolution** | Template resolution, text box binding, tokens and variables, copyright notice, `RenderModel`, problem reporting, new-slide helper |
| **C1.2b: Copy rules** | Fork a reference into a copy and revert, duplicate a Show, create a Service from a Service Template, duplicate a Service, skip rules, song-edit policy, `IdRemapper` |

## Decisions for you to confirm

Each has my recommendation. If you agree with all of them, say so and I'll execute. If you disagree with one, tell me which.

| # | Decision | Recommendation and reason |
|---|---|---|
| 1 | **A detached Text Box remembers its Template Box name.** In the model, `BoundTemplateBoxName` becomes `TemplateBoxName`, and a non-null `Geometry` means "detached". `IsDetached` is derived. | The FRD says a detached box "still uses the Template's defaults" (TPL-022) and "Reattach restores binding" (TPL-023). Both need to know which Template Box it came from, which the FRD sketch (null name = detached) throws away. "Detach" copies the box's current geometry into the box so it doesn't jump. "Reattach" clears the geometry. Small change to C1.1 types and golden files, no saved files exist yet. |
| 2 | **Missing Templates fall through, then a built-in fallback.** Resolution order is Slide override, Show default, Category default, Library default (TPL-010). If an ID points at a deleted Template, it's skipped and reported (TPL-002). If nothing resolves, a built-in plain template is used (black background, one full-size box, one copyright box along the bottom). | The Output must always render something (LIB-011 spirit, DEC-012). Never throw. |
| 3 | **Template Box names match case-insensitively.** `Body` finds `body`. | Forgiving for typed names, no real downside. |
| 4 | **The copyright notice goes on the first/last *displayed* slide.** Slides skipped in this Service (SVC-021) are ignored when deciding "first" and "last". | If slide 1 is skipped, the copyright notice would otherwise silently never appear. Reporting obligations matter. |
| 5 | **A Show Copy keeps the skip list and the remembered Placeholder.** A new abstract `ShowItem` base holds `SkippedSlideIds` and `FilledFrom`, shared by `ShowReferenceItem` and `ShowCopyItem`. | Otherwise forking a song drops "verses 3 and 4 skipped", and reverting loses them. |
| 6 | **Forking keeps the Service Item ID and all Slide and Text Box IDs, and gives the local Show a new Show ID.** | Item-level Actions and Cues keep pointing at the right things. The new Show ID avoids two Shows with the same ID in memory. |
| 7 | **Empty metadata renders literally in the copyright line.** A song with no authors gets ` —  · © ...` with the gaps. No smart punctuation clean-up. | Predictable. The pre-service check (CHK-001) already flags songs missing copyright or authors. |
| 8 | **Token keywords match case-insensitively; anything unrecognized in `{{ }}` stays as literal text.** Variable and Timer names: letters, digits, underscores (VAR-001). | Typos like `{{preachr}}` become a normal (undefined) Variable token and get flagged. Other braces text is never destroyed. |
| 9 | **Outside a Service, Variable and Timer tokens show as their markup** (`{{preacher}}`, VAR-003). Show metadata and church license tokens always resolve. | As in the FRD. |
| 10 | **Resolution reports problems instead of failing.** `RenderModel.Problems` lists: missing Template, Template Box not found (TPL-027), detached box with no geometry, Variable empty or undefined (VAR-005), Timer undefined. The pre-service check (C6.2) will just read this list. | One source of truth. No duplicate logic in the check. |
| 11 | **Resolution isn't cached in the Domain.** Each call is cheap and pure. Caching of rendered slides is the renderer's job (C2.1). | Keeps the Domain simple. |

## C1.2a: Slide resolution

New code in `ChurchSlides.Domain/Resolution/` plus small model changes.

**Model changes** (golden files regenerated, reviewed by hand):
- `SlideTextBox`: `BoundTemplateBoxName` → `TemplateBoxName`, add computed `IsDetached` (`[JsonIgnore]`).
- `RichText.WithoutFormatting()` (TPL-025 "Clear formatting").

**Inputs**
- `TemplateSet`: immutable snapshot of Templates by ID, Categories by ID, and the Library's default Template ID.
- `ResolutionContext`: the `TemplateSet`, `LibrarySettings` (church license, copyright format), the current `Show`, the optional `Service` (null means "viewed outside a Service"), and a `SlidePosition` (is this the first / last displayed slide of the Show).
- `SlidePosition.For(show, slide, skippedIds)` computes position honoring skips (decision 4).

**Outputs** (immutable)
- `RenderModel`: resolved `Background`, `TextBoxes`, `Problems`, and the ID of the Template used.
- `RenderTextBox`: final geometry, alignment, line spacing, outline, shadow, paragraphs, and `IsCopyright`.
- `RenderRun`: text plus fully resolved font family, size, color, bold, italic. `RenderTimerRun`: Timer name plus the same formatting and the Timer's warning threshold and color. The renderer fills in the live value.
- `RenderProblem`: sealed hierarchy as in decision 10.

**Functions**
- `TemplateResolver.Resolve(slide, context)`: the order in TPL-010 with fall-through and fallback.
- `SlideResolver.Resolve(slide, context) → RenderModel`: bind boxes (TPL-021..023, 027), merge formatting (run beats Text Box override beats Template default, TPL-024), resolve tokens (VAR-002..006, CCLI-003), inject the copyright box (CCLI-004/005), pick the background (slide override beats Template, SLD-006).
- `TokenMarkup.Parse(string) → inlines`: turns `{{...}}` text into text and token runs (used for the Library copyright format and, later, editor paste).
- `VariableNames.IsValid` and `Normalize` (VAR-001: letters, digits, underscores, case-insensitive).
- `TextBoxBinding.Detach`, `Reattach` (decision 1).
- `Slides.CreateBlank(template, label)`: one bound, empty Text Box per non-copyright Template Box (TPL-026).

**Tests (named by requirement ID, table-driven where it helps)**
1. **TPL-010 order:** every combination of the four levels present/absent gives the expected winner. A deleted ID at any level falls through and reports `TemplateMissing`. Nothing resolves gives the fallback.
2. **TPL-003/013:** the same Slide resolved against two different Template sets gives different output, with the Slide untouched.
3. **TPL-020..023:** bound box takes Template geometry and defaults. Detached keeps its geometry and still takes defaults. Detach then Reattach round trips. A detached box doesn't move when detached.
4. **TPL-024/025, AS-05:** inline red text stays red when the Template changes, unformatted text follows the Template, a Category Template change moves bound boxes but not detached ones, "Clear formatting" removes inline formatting.
5. **TPL-026/027:** blank slide gets the right boxes (no copyright box). Missing box name renders in the first non-copyright box and reports the problem without losing content. Template with no usable box.
6. **VAR-001..006:** name validation table. Defined, empty, undefined, case-insensitive lookup, formatting applied to the resolved value, markup shown outside a Service.
7. **CCLI-003..005:** each metadata token. Copyright box matrix: placement (None, First, Last) × position (first, last, only, middle) × public domain × Template has a copyright box or not. Skips honored.
8. **Tokens:** `TokenMarkup.Parse` for every token form, unknown braces, unbalanced braces, adjacent tokens, empty input. Round trip with `Token.ToMarkup()`.
9. **SLD-006:** slide background override beats Template, solid color and image.

## C1.2b: Copy rules

New code in `ChurchSlides.Domain/Editing/`.

**Model change:** new abstract `ShowItem : ServiceItem` holding `SkippedSlideIds` and `FilledFrom` (decision 5). `ShowReferenceItem` and `ShowCopyItem` derive from it.

**Functions**
- `ShowCopying.Fork(reference, catalogShow) → ShowCopyItem` (SVC-022, decision 6) and `Revert(copy) → ShowReferenceItem` (SVC-024, fails cleanly if there is no origin). Skip list carries both ways, minus slides that no longer exist.
- `ShowCopying.Duplicate(show) → Show` (DEC-005): new Show, Slide and Text Box IDs. Every internal reference (Cue slide IDs, Action targets that point at slides in this Show) is remapped. External references (Category, Templates) are untouched.
- `ServiceCopying.FromTemplate(serviceTemplate, name, date) → Service` (SVC-001, SVC-030, VAR-004): new Service and Service Item IDs, Variables with defaults, Timers, Actions, Rehearse mode, link to the source template. Actions that name items (`GoToItem`, `GoToSlide` with an item) are retargeted to the new IDs. `ServiceCopying.Duplicate(service)` likewise.
- `IdRemapper`: the shared engine for the above (old to new maps for Shows, Slides, Text Boxes, Service Items; rewrites Actions and Cues).
- `SkipRules`: `CanSkip(show)` is false when the Show has Audio with Cues (SVC-025), `SetSkipped(item, slideId, skipped)` enforces it and returns a reason the UI can display.
- `EditPolicy.ForSlideEdit(show)` (SVC-022): Presentation means auto-fork, Song means prompt with catalog edit as default.

**Tests**
1. **Fork:** Slide IDs, Text Box IDs and Service Item ID identical, new Show ID, skip list and Placeholder memory kept, Actions kept (SVC-022/023, AS-06).
2. **Revert:** returns a reference with the origin Show ID, drops skips for slides that were deleted, fails without an origin (SVC-024).
3. **Duplicate Show (DEC-005):** a sample Show with audio cues and Actions duplicated. **No Slide, Text Box or Show GUID from the original appears anywhere in the copy's JSON.** Only external IDs (Category, Templates) remain. Cues point at the new Slide IDs. The original is unchanged.
4. **Instantiate from Service Template (SVC-035, AS-04):** no old item ID remains. A `GoToItem` Action points at an item that exists in the new Service. Variables get defaults. Mode is Rehearse. Changing the template afterward doesn't affect the Service (immutable by construction, asserted).
5. **Duplicate Service:** same guarantees, local Show copies keep their inner IDs.
6. **SVC-025 / SVC-021:** skipping allowed or refused with reason, for Shows with and without cues.
7. **SVC-022 policy:** Song versus Presentation.
